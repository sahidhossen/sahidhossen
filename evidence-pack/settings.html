Settings

Only Jira admins can change settings. Everyone else sees them read-only. Every change is recorded in the change log at the bottom of the page.

Frameworks

How changes are judged

SettingWhat it does
What counts as approvalA status, an approval in the ticket panel, or either. See How the checks work.
Approval statusesMoving a change into one of these counts as approval.
Implementation statusesMoving a change into one of these means work started. It must happen after approval, by someone else.
Emergency label and windowChanges with this label may be approved within the window after work starts.
Require code evidenceAdds a fourth check for a linked pull request, commit, deployment or link.
Block self-approvalStops an assignee from approving their own change in the panel.
Move ticket on approvalMoves the issue to the first approval status when approved in the panel.

Access

Who can build packs and Who can approve changes take Jira groups. Leave them empty to allow everyone. Jira admins always can.

Monthly packs

Add a schedule with a name, JQL and sample size. On the first day of each month, a pack for the previous calendar month is built and stored in History. Run now builds last month's pack immediately.

Your data

Export all data downloads a JSON file with settings, schedules, the change log, the pack log and all approval records.
